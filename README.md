# 🏡 StayVibe – Airbnb Clone

StayVibe is a full-stack Airbnb clone web application that allows users to explore, create, and manage property listings with authentication, reviews, and image uploads.

---

## 🚀 Features

- 🔐 User Authentication & Authorization (Passport.js)
- 🧾 Session Management using MongoDB Atlas (connect-mongo)
- 🏠 CRUD operations for Listings
- ⭐ Add & Delete Reviews
- ☁️ Image Upload with Cloudinary & Multer
- 🔔 Flash Messages for user feedback
- 🛡️ Protected Routes using Middleware
- 🎨 Responsive UI with EJS & Bootstrap

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **Frontend:** EJS, Bootstrap
- **Authentication:** Passport.js
- **Session Store:** express-session, connect-mongo
- **Image Storage:** Cloudinary, Multer
